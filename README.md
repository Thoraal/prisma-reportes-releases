# Prisma Reportes

Reportes diarios de compras y ventas de divisas por sucursal, listos en Microsoft Excel.

Funciona con una o varias empresas: cada una se reconoce por la razón social de su archivo y usa su propio perfil local (sucursales, nombres visibles, columnas, operadores excluidos y encabezados). El programa no incluye datos de ninguna empresa y trabaja sin conexión.

## ⬇️ Descargar

**[Descargar la última versión para Windows (64 bits)](https://github.com/Thoraal/prisma-reportes-releases/releases/latest/download/Prisma-Reportes-Windows-x64-Setup.exe)**

Este enlace siempre entrega la versión más reciente. Todas las versiones y sus notas: [Releases](https://github.com/Thoraal/prisma-reportes-releases/releases/latest).

## Instalación

1. Descargue el instalador y ábralo.
2. Siga el asistente. No requiere permisos de administrador ni herramientas adicionales.
3. Abra **Prisma Reportes** desde el menú Inicio o el escritorio.

> Si Windows muestra **«Windows protegió su PC»**, el instalador aún no lleva firma de código (Authenticode). Elija **Más información › Ejecutar de todas formas**. Puede comprobar el archivo con la suma SHA-256 publicada en cada versión (`SHA256SUMS.txt`).

Requisitos: Windows 10 u 11 de 64 bits. Para abrir el reporte en Excel se necesita **Microsoft Excel de escritorio** (Microsoft 365, Office 2016 o posterior).

## Actualizaciones

Prisma Reportes comprueba al iniciar si hay una versión nueva y la ofrece en **Configuración › Actualizaciones**. Las actualizaciones están firmadas y la aplicación verifica la firma antes de instalarlas. Sus perfiles y preferencias se conservan.

## Desinstalar

**Configuración de Windows › Aplicaciones › Aplicaciones instaladas › Prisma Reportes › Desinstalar.**
